Now Playing · Setup

Spotify → Last.fm → OBS. Viewers type !last, !song, !top or !мясо and the answer shows up on stream.

📖 Инструкция на русском — как подключить оверлей

Оверлей показывает на стриме трек, который играет у тебя в Spotify, и отвечает на команды чата. Все настройки хранятся только в твоём браузере — автор сайта их не видит. Сервер, Spotify Premium и приложение Twitch не нужны.

1. Last.fm (5 минут, один раз)

  1. Зарегистрируйся на last.fm — это бесплатно.
  2. Открой Settings → Applications и подключи Spotify. Теперь Last.fm видит, что ты слушаешь.
  3. В Settings → Privacy выключи Hide recent listening.
  4. Открой last.fm/api/account/create, впиши любое название и описание, Callback URL оставь пустым. Скопируй API key (не Shared secret).

2. Настройка на этой странице

  1. 01 — впиши ник Last.fm.
  2. 02 — вставь API key и нажми Check. Должно появиться «✓ Works» с последним треком. Включи музыку в Spotify, если трека нет.
  3. 03 — впиши имя своего Twitch-канала. Выбери, куда выезжает панель команд: Below, если оверлей будет в верхнем углу, Above — если в нижнем. Выставь кулдауны в минутах.
  4. 05 — нажми Copy.

3. OBS

  1. Источники → + → Браузер.
  2. В поле URL вставь скопированную ссылку, ширина 400, высота 420.
  3. Перетащи источник в нужный угол экрана. Пустое место вокруг плашки прозрачное.

Заказ треков

  1. Открой twitchtokengenerator.com, выбери Bot Chat Token и войди основным аккаунтом.
  2. Скопируй Access Token, вставь его в блок 04 и нажми Check. С этого аккаунта бот будет отвечать в чат.
  3. Держи эту страницу открытой во время стрима: наверху будет список заявок с кнопкой «Open in Spotify». Трек включаешь сам, а когда он доиграет, заявка пропадёт.

Команды для зрителей

  • !song — подсветить текущий трек.
  • !last — последние 5 треков.
  • !top — твой топ-5 за выбранный период.
  • !мясо — реакция 🥩 на текущий трек.
  • !sr Исполнитель - Трек — заказать трек (не больше 2 заявок, раз в 5 минут).
  • !queue — три следующие заявки в чате.
  • !next, !remove N и !clear — следующая заявка, удалить заявку №N, очистить очередь. Только для тебя и модераторов. На этой странице для этого есть кнопки ✕ и Clear queue.

Если что-то не работает

  • Check Last.fm settings на плашке — неверный ник или ключ, либо скрыта история прослушиваний (пункт 1.3).
  • Last.fm connection error — нет связи с Last.fm, проверь интернет или VPN.
  • Трек не меняется — проверь, что Spotify подключён к Last.fm, и что трек появляется у тебя в профиле на last.fm.
  • Изменил настройки — заново скопируй ссылку и вставь её в OBS.
  • Не показывай ссылку из пункта 05 на стриме — в ней твой ключ Last.fm и токен Twitch.
